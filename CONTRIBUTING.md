# Contributing to Research Repository

This repository contains research materials such as literature reviews, surveys, competitor analysis, and user studies.

---

## Branch Strategy

- `main` → Approved research only
- `draft/<research-topic>` → Work in progress
- `fix/<issue-number>` → Corrections after review

Example:
- `draft/competitive-analysis-uber`
- `draft/user-survey-results`

---

## Data Privacy Rules

- Do NOT commit personal identifiable data (PII)
- Always anonymize survey responses
- Store consent forms offline (Google Drive or local secure storage)
- Commit only summarized or cleaned data

---

## Commit Messages

- `research:` Add research findings or sources
- `docs:` Update reports or analysis documents
- `feat:` Add survey, dataset, or new section
- `fix:` Correct data or analysis issues

Examples:
- `research: add literature review on garage systems`
- `docs: update competitor analysis matrix`
- `feat: add user survey summary`

---

## File Naming

- `literature-review-garage-systems.md`
- `competitor-analysis-v2.md`
- `survey-summary-2026.md`

---

## Pull Requests

- Minimum 1 peer review required
- Include sources/URLs for all external references
- Ensure data is cleaned and anonymized
- Do not merge your own PR
